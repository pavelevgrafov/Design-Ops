# skins-pro/ — Pro tier skins (placeholder, v7.0)

Зарезервировано под curated skins для Pro tier. Базовые скины
(`skins/base-site`, `skins/base-app`) — бесплатны и полны; они не урезаются
никогда (принцип: core полный, ecosystem — bonus).

Важно решение владельца (зафиксировано в ТЗ v7.0): **платных скинов нет** —
монетизация через packs и поддержку, не через ограничение визуального
разнообразия. Директория остаётся для curated бесплатных скинов, которые
будут добавляться по мере появления проверенных направлений (skin =
inspiration + tokens, не копия чужих дизайнов; auto-archive без обновлений
6+ месяцев).
