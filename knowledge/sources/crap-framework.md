## Что это
Четыре классические рамки. CRAP (Робин Уильямс): контраст — различия
решительные (полумеры 16px vs 18px — конфликт без иерархии); повтор —
один стиль = одна роль; выравнивание — ничто не случайно, «почти
выровнено» читается как небрежность; близость — связанное рядом.
Норман: аффорданс + сигнификатор + маппинг + обратная связь — разрыв
цепочки = «непонятный» интерфейс; правило «интерактивное выглядит
интерактивным» = A.13. Рамс: «тихий» базовый стиль (принципы 5, 8, 10).
Краг: не заставляй думать; каждый клик однозначен; убирай половину слов.

## Использование в пайплайне
- K2B/K3: CRAP как D-check suite — 4 проверки на каждый экран (контраст
  уровней ≥ 1.25×, повтор стилей ролей, общие оси, группировка отступами).
- K2A: аффорданс-инвариант — каждый кликабельный элемент имеет визуальный
  маркер и hover-состояние; каждое действие — отклик < 400 мс.
- K2B divergence: принципы Рамса — философия «тихого» base skin.

## Границы
- CRAP — быстрый фильтр, а не полный аудит: не заменяет D-checks и
  human gates.
