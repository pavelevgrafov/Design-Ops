## Что это
Индустриальный стандарт — три слоя: примитивы (blue-500: #3B82F6,
space-4: 16px — без контекста), семантика (color-action-primary,
text-body-default — роль; делает возможной темизацию одной подменой),
компонентные (button-primary-bg — ссылаются только на семантику, никогда
напрямую на примитивы). Именование: консистентность важнее идеальности;
ясность важнее краткости; семантика остаётся семантикой (не создавать
семантический токен blue); порядок категория → свойство → модификатор;
проектировать на рост (состояния, режимы, шкалы). Атомарный дизайн
(Фрост): атомы → молекулы → организмы → шаблоны → страницы; решение
принимается на самом низком корректном уровне. Машиночитаемость —
требование эпохи агентов: система в JSON-токенах и конфигах — harness,
сужающий пространство решений модели до бренда. Минимальная система:
цвета, типографика, отступы, 3 тени, 3–4 радиуса, 2–3 easing + длительности,
состояния интерактивных элементов.

## Использование в пайплайне
- A.21: primitive → semantic → component, никогда component → primitive
  (invariant).
- K2A/K2B: рефакторинг skins в трёхслойную архитектуру; compile-tokens
  генерирует слои раздельно.
- K3: D.37 / pack token-validator — проверка ссылок между слоями.
- Рестайл = правка токена + compile-tokens.py (DoD v6.0 усиливается).

## Границы
- Три слоя — для продуктовых skins; одноразовый divergence-прототип K2B
  может работать на семантике напрямую до merge.
