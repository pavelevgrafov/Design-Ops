## 2. Generative rules

- **[A.7]** A restyle edits tokens, never components — markup is not a skin property.  _(also checked: D9, D22)_
- **[A.12]** Every async block is a 7-state automaton: idle, loading, skeleton, populated, empty, error, success. Designing only the ideal state is a defect.  _(also checked: D.38)_
- **[A.13]** Interactive looks interactive: every clickable carries a visual marker + hover state; every action answers within 400 ms.
- **[A.14]** One primary CTA per view; secondary actions are outline/ghost.
- **[A.15]** All sizes in rem, never px — layout must survive system font size and 200% zoom.  _(also checked: D4)_
- **[A.16]** No cards inside cards.
- **[A.17]** Animate transform and opacity only; interruptible by new input; a prefers-reduced-motion quiet version always.  _(also checked: D.29, D.35)_
- **[A.18]** Semantic HTML before ARIA; one h1; heading hierarchy continuous.  _(also checked: D.28)_
- **[A.19]** Never colour alone: status = colour + icon + text.
- **[A.20]** Mobile-first; components adapt, not pages; a breakpoint goes where the content breaks, not where a device is.
- **[A.21]** Tokens flow primitive -> semantic -> component, never back down the chain.  _(also checked: D.37)_
