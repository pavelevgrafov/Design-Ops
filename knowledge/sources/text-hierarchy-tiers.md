## Что это
Модель Refactoring UI: первичный текст — полная непрозрачность, почти-чёрный
с подтоном (#1C1917–#111827, не #000); вторичный — 70–80% (#57534E/#374151);
третичный — 40–50% (#A8A29E/#9CA3AF). Зазор между ступенями должен быть
очевидным на взгляд, не вычисляемым (#333 vs #555 — ошибка). Шесть
инструментов иерархии: размер (скачок ≥ 1.25×), вес (400/500–600/700),
цвет, пространство, позиция, повтор. Правила: один первичный акцент на экран
(A.14); сначала дизайн в сером, цвет — последним слоем; squint test.

## Использование в пайплайне
- K2A/K2B token system: --text-primary / --text-secondary / --text-tertiary
  как семантические токены.
- K2B design rule: «усиление главного через ослабление второстепенного» —
  запрет гонки вооружений (больше/жирнее/ярче).
- K3: D.31 squint test — иерархия читается при blur; проверка без контента
  (заглушки вместо текста сохраняют структуру).

## Границы
- Проценты — ориентир непрозрачности, финальные значения фиксируются в
  токенах skins и проверяются D.25 (контраст WCAG).
