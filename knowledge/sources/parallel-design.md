## Что это
Исследование NN/g (Nielsen & Faber, 1996): дизайн, собранный из лучших
идей нескольких независимых параллельных вариантов, превосходит средний
одиночный вариант; итерация поверх объединённого даёт дальнейший прирост
(конкретные проценты в пересказах расходятся — ориентир метод, не цифра).
Фазовая последовательность из 10 шагов: структура → иерархия →
пространство → типографика → цвет → глубина → моушн → состояния →
доступность → полировка. Сжатие всех решений в одну генерацию — главная
причина посредственности. Цикл оценки: критика (структура) → аудит
(технические дефекты) → полировка (микродетали) → нормализация (сверка с
дизайн-системой). Экспресс-тесты: squint, 5 секунд, серый, клавиатура.
Мета-обзор 145 исследований: умеренные ограничения дают максимум
креативности (U-образная связь).

## Использование в пайплайне
- A.23: минимум 3 directions в contact sheet (invariant) — merge по
  умолчанию сохраняется из v6.0.
- K2B: design review audit = цикл критика → аудит → полировка →
  нормализация после contact sheet, до merge.
- Pipeline: фазовая последовательность — process invariant всего конвейера
  (K0–K4 отражает шаги 1–10).
- K3: экспресс-тесты — D.31–D.34 (warning-уровень).

## Границы
- В песочницу переносятся решения, не код; варианты агента почти бесплатны,
  но merge утверждается human gate (A.2, A.5 сохраняются).
