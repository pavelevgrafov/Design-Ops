## Что это
Десять эвристик NN/g (1994, формулировки стабильны 30+ лет): видимость
статуса, соответствие реальному миру, контроль и свобода, консистентность,
предотвращение ошибок, узнавание вместо припоминания, гибкость,
эстетика и минимализм, восстановление после ошибок, помощь.
Формализация для агента: №1 → «каждое действие даёт отклик»; №4 → «один
термин = одно понятие»; №5 → «disabled вместо ошибки, маски ввода»;
№8 → «убрать то, без чего экран работает»; №9 → «ошибка = конкретика +
действие, без кодов». Эвристики №5 и №9 — пара: сначала невозможность
ошибки, потом восстанавливающие сообщения.

## Использование в пайплайне
- K3 quality-guardian: эвристики как аудит-протокол quality report —
  прогон сгенерированного интерфейса по 10 пунктам с артефактом на каждый.
- K0: №2 — discovery brief на языке пользователя.
- K1/K2B: №3 (undo/закрытие модалки), №6 (меню вместо команд), №7
  (шорткаты, дефолты для опытных).
- Кейс-маяк: Therac-25 — цена нарушений №1/№5/№9.

## Границы
- Эвристика — чек-лист для reviewer, не дизайн-решение: агент проверяет
  формализованные правила, субъективная оценка остаётся за человеком.
