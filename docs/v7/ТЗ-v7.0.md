# ТЗ — Design Production Pipeline v7.0

Статус: draft для утверждения владельцем. Дата: 2026-08-03.
База: v6.0 (main, HEAD 28b54f2). Основание: исследование «Pipeline 7 (concept)», анализ в `01-Анализ-документа-П7.md`.

---

## 1. Цель релиза

Повысить качество и устойчивость продукта pipeline за счёт формализованных правил UI/UX (энциклопедия), расширенной машинной верификации (D1–D38) и усиленного визуального этапа K2B — не меняя фундаментальную архитектуру v6.0 (конвейер K0–K4, гейты, контракт как single source of truth). Дополнительно: минимальная экосистема вокруг продукта и подготовка монетизации.

Формула релиза: **v7.0 = v6.0 + знания + проверки + токены + K2B-аудит + экосистема MVP**. Никаких ломающих изменений конвейера.

## 2. Scope

### 2.1. Входит в v7.0

1. **Инварианты A.12–A.24** (AGENTS.md) — из энциклопедии UI-дизайна.
2. **Knowledge vault**: 17 новых evidence notes E.22–E.38 + регенерация index.yaml.
3. **D-checks D.25–D.38** с tiered-применением (Tier 1 blocking / Tier 2 warning).
4. **Token system**: расширенные категории, dark elevation, motion, трёхслойная архитектура.
5. **5 новых packs**: ai-look-detector, contrast-checker, token-validator, state-generator, copy-linter.
6. **K2B enhancement**: 7-axis divergence, tiered ban-list, design review audit, awwwards-reference pack.
7. **K0/K1 enhancement**: AJTBD-lite, RAT-lite, slash commands.
8. **Экосистема MVP**: GitHub Discussions, Radar MVP, Docs Portal (MkDocs), Showcase из harvest.
9. **Подготовка монетизации**: trademark notice, структура *-pro директорий, tier checking, README repositioning. Платежи НЕ подключаем.

### 2.2. Не входит в v7.0 (backlog v7.1+)

- Mobile app design (профиль mobile, mobile-packs) — требует переисследования, раздел утерян.
- A2UI preview mode для K2B — v7.5.
- MCP bridge pack, Figma bridge pack — v7.5.
- Pack Marketplace, Starter Gallery, Skin Store (расширенный), Research Lab, Benchmark Suite (golden dataset), Token Observatory — v7.1–v8.0.
- Stripe/payments, Pro tier запуск — после v7.0, отдельным решением.
- Enterprise, certification, hosted version — v8.0+.
- Scope guard из исследования действует полностью: no runtime Generative UI, no React-only tools, no BaaS, no white-label, no video/motion generation.

### 3.4. Token system

Новые категории в skins/base-*/tokens.json и compile-tokens.py:

- Typography: --font-size-xs…4xl (модульная шкала 1.125–1.333), --line-height-body/heading, --font-weight-regular/medium/bold, --letter-spacing-tight/normal/wide, fluid через clamp().
- Spacing: --space-1 (4px) … --space-16 (64px), 8pt grid.
- Color: --color-neutral-50…950, --color-semantic-error/warning/success/info, --color-text-primary/secondary/tertiary, HSL-модель, не чистый чёрный для текста.
- Shadow: --shadow-sm/md/lg (двухслойные).
- Radius: --radius-sm/md/lg/full.
- Motion: --duration-fast/normal/slow (100–200 / 200–500 / 500–700 мс), --ease-out/in/in-out, --spring-bounce/duration.
- Elevation (dark): --elevation-0dp…24dp (white overlay %), фон ≈ #121212, десатурация ~20%, белый текст ~87%.
- Архитектура: primitive → semantic → component (A.21); проверка — D.37 / token-validator.

Требование: restyle любой страницы = правка токена + compile-tokens.py (DoD v6.0 сохраняется); starters проходят recheck после расширения.

### 3.7. Экосистема MVP

1. **GitHub Discussions** — включить в репо, категории: General, Showcase, Packs, Help, Ideas.
2. **Radar MVP** — `.github/workflows/radar.yml` (weekly cron) + один Python-скрипт: 5 запросов к GitHub search API (ui-generator, design-system, design-tokens, visual-regression, ai-design), фильтры (≥100 stars, age >3 мес, push <1 мес), digest топ-5 как GitHub issue. Стоимость $0. Hard thresholds против шума.
3. **Docs Portal** — MkDocs + GitHub Pages: getting-started, pipeline (K0–K4), skills, packs, knowledge, changelog. Правило: PR с изменением skill без обновления docs — блокируется.
4. **Showcase** — auto-populate из harvest.py: каждый harvested starter = запись галереи (metadata + screenshot + before/after).

## 4. Нефункциональные требования

- **Обратная совместимость**: v6.0-контракты читаются; contract-migrate.py при необходимости расширяется до schema 7.0. main и тег v6.0 не трогаем.
- **Честная деградация**: новые checks при отсутствии capability (playwright и т.п.) — явный unavailable, вердикт не повышается (A.6 сохраняется).
- **Контекстный бюджет**: SKILL.md ≤ 500 строк; энциклопедия живёт в references с progressive disclosure.
- **Производительность pipeline**: Tier 1 checks ≤ +30% к времени K3 против v6.0 на app-dashboard starter.
- **macOS/BSD-совместимость** скриптов (стандарт v5.2+).
- Self-test: ≥ 49 проверок, зелёный (0 failed) перед выпуском.

## 5. Критерии приёмки (Definition of Done релиза)

1. Все задачи фаз 1–6 из `Бэклог-v7.0.md` закрыты или явно перенесены в v7.1 с записью в decision log.
2. Self-test зелёный: ≥ 49 passed / 0 failed (skipped — только с причиной).
3. Eval-прогон P01 (и P17–P23 где применимо): ≥ 10/12, нули в blocking criteria отсутствуют.
4. Starters recheck зелёный на новых токенах; restyle = token edit + compile-tokens.
5. AGENTS.md, README.md, INSTALL.md, CHANGELOG обновлены и синхронизированы (docs = code).
6. Тег v6.0 создан ДО merge v7.0 (точка отката); v7.0 выкатывается merge в main + тег v7.0.
7. Экосистема MVP работает: Discussions включены, Radar создал первый digest-issue, Docs Portal опубликован.
8. Чек-лист `Чеклист-выпуска-v7.0.md` пройден полностью.
